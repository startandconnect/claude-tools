Installiere mir bitte den Claude-Code-Mod „cache-context“ aus https://github.com/startandconnect/claude-tools.

1. Führe `claude plugin marketplace add startandconnect/claude-tools` aus, dann `claude plugin install cache-context@claude-tools`.
2. Prüfe mit `claude plugin list`, dass cache-context installiert und aktiv ist.
3. Findest du den Befehl `claude` nicht, sag mir, dass ich in Claude Code selbst `/plugin marketplace add startandconnect/claude-tools` und danach `/plugin install cache-context@claude-tools` eingeben soll.
4. Sag mir zum Schluss, dass ich `/reload-plugins` eingeben oder Claude Code neu starten soll, und erklär mir in drei kurzen Sätzen, was der Mod tut und wie ich die Automatik mit `/session-automatik aus` abschalte.
